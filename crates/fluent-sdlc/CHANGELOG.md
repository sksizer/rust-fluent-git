# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-07-14

### Added

- add fluent-gh crate with pr, issue, and repo operations
- add fluent-claude crate wrapping Claude Code CLI
- add fluent-lima crate wrapping limactl VM operations
- add fluent-brew crate wrapping Homebrew CLI operations
- add crate wrapping Cloudflare Wrangler CLI operations

### Changed

- migrate to cargo workspace with fluent-core, fluent-git, fluent-sdlc
